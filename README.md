# credit-card-fraud-detection
Real-time Credit Card Fraud Detection system using XGBoost achieving 97% precision with interactive Streamlit dashboard

# Project Overview
Real-time Credit Card Fraud Detection system using 
Machine Learning to identify fraudulent transactions 
with high precision.

# Technologies Used
- Python
- XGBoost
- Scikit-learn
- Streamlit
- Plotly
- Pandas & Numpy

#  Model Performance
| Metric | Score |
|--------|-------|
| Precision | 72% |
| Recall | 85% |
| F1-Score | 78% |
| Accuracy | 99% |

# How to Run
pip install -r requirements.txt
streamlit run app.py

# Project Structure
- train.py → Model training
- app.py → Streamlit dashboard
- model/ → Saved model
- data/ → Dataset
